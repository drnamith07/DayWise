# DayWise — Your AI LifeOS (Demo Prototype)

A front-end concept demo for a student-focused AI life assistant. It brings academic planning, screen habits, mood check-ins, sleep, activity and wearable-style signals into one daily view.

## Run the demo
1. Download and extract this folder.
2. Open `index.html` in a browser.

No installation or server is required.

## Important prototype note
This is an interactive visual prototype using illustrative sample data. It does **not** connect to phone apps, operating-system screen-time APIs, smartwatches, medical devices, calendars or learning platforms. The assistant responses are predefined demo responses, not a live AI model. Real integrations require platform-supported APIs, user permission, secure data handling and appropriate device compatibility. Health values are not medical advice.

## Main demo areas
- Overview with cross-life daily insight
- Mind & body signals and mood check-in
- Academic tasks and daily timeline
- Connected services and privacy/permission concept
- DayWise assistant panel
