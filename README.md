# DayWise – Student Daily Assistant

DayWise is an AI-powered student assistant that helps students manage academic tasks, daily routines, health, and productivity in one place.

## Key Features

- Academic Management: Add, view, and complete tasks with deadlines.
- Health & Fitness: Track daily water intake and exercise.
- Daily Summary: View daily activities and progress.
- MCP Integration: Access basic tools through the Model Context Protocol.

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: SQLite
- MCP: Python MCP SDK

## Run the Project

    pip install -r requirements.txt
    python3 app.py
